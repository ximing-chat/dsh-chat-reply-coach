# 阶段 × 情绪策略库

工作流程第 2、3 步查这里。先定情绪，再定阶段，最后取交集里的策略。

---

## 一、四种情绪倾向

| 情绪 | 典型信号 | 这一条要达成什么 |
| --- | --- | --- |
| 积极 | 有反问、有表情、接你的梗、主动延伸话题、回复变快变长 | 接住，并往前推一小步 |
| 中性 | 「嗯」「哦」「还行」「看情况」，字少但没关门 | 降低对方的回复成本 |
| 冷淡 | 单字、隔很久才回、不反问、句号收尾、已读不回 | 止损，留住体面 |
| 试探 | 反问、玩笑式质疑、「你是不是对谁都这样」「你猜」、忽冷忽热 | 接住，不自证，不被带节奏 |

### 积极

- 要做：先回应内容，再给一点情绪；加码但不刷屏；顺手埋一个下次能接的钩子。
- 别做：一次把话题聊到底；立刻表白或要承诺；连发三条等回复。
- 可用句式：「你这么说我更想知道了，展开讲讲」「刚看到这句笑出声」「行，这事我记你一笔」。

### 中性

- 要做：给具体的东西（一个信息、两个选项、一个更好接的话题）；一次只问一件事。
- 别做：连问三个问题；追问「你怎么这么冷淡」；发长文。
- 可用句式：「懂了，那你更偏 A 还是 B」「我猜你是懒得打字，那我换个好答的」「行，我先报个到，你想聊了随时接上」。

### 冷淡

- 要做：减量、给台阶、把话说到可以自然结束；隔一两天换个由头再来一次；**两次没有回应就停**。
- 别做：追问「在吗」「怎么了」「是不是我说错话了」；解释；连发；换号。
- 可用句式：「看你最近挺忙，先不打扰」「好，那我先撤，回头聊」「（隔天换话题）突然想到个事跟你说——」。

### 试探

- 要做：用轻松的态度接；给态度不给证明；把球抛回去，但要接得住。
- 别做：急着解释；赌咒发誓；反查对方；被一句话激怒。
- 可用句式：「这话问得，我得想想怎么答才不亏」「猜对了有奖励吗」「对别人我不知道，对你是挺上心的」（注意别用力过猛）。

## 二、四个阶段

每个阶段给：适用信号 → 目标 → 可用策略 → 句式骨架 → 禁忌。

### 破冰

**适用信号**：刚认识或刚加回来，还没找到共同话题，回复礼貌但短。

**目标**：让对方觉得跟你聊天轻松、不累，愿意有下一次。

**可用策略**

1. 抓关键词发散：她话里任何一个具体名词，都能接一个细节、一个小故事，再带一个轻问句。
2. 自我暴露一小段：说自己的一个具体场景（不是履历），让她有得接。
3. 短句留白：一条只说一件事，不把话说完。
4. 不查户口：把「你多大 / 做什么工作」换成「先说自己，再顺带问」。

**句式骨架**：接住她的话 + 一个具体细节 +（可选）一个轻问句

**禁忌**：连问三个问题；汇报式自我介绍；发「在吗」；一上来夸外貌；长篇大论。

**依据**：话术整理里的「聊天基调要轻松有趣」「不要查户口式聊天」「抓住话题关键点发散」「微信聊天短小精悍」。

### 升温

**适用信号**：开始互相接梗、主动分享、出现「哈哈」「你也……」，回复频率变快、篇幅变长。

**目标**：从交换信息转向交换情绪，形成「只有我们懂」的氛围。

**可用策略**

1. 先接情绪再接事实：她说累，先接「累」，别急着给方案。
2. 具体化夸奖：夸细节，不夸标签。
3. 轻调侃：确定熟络了再用；调侃事，不调侃人。
4. 埋钩子：在聊得最好的时候收一下，留个下次能接的点。
5. 识别转折点：回复变快、变长、主动找你，就是窗口；**窗口出现后一周内推进**，拖过去热度就凉了。

**句式骨架**：接情绪 + 一点自己的感受或经历 + 留钩子

**禁忌**：一次把话题聊到底；反复聊同一个话题；长期当情绪垃圾桶（她真遇到事时接一次可以，别变成惯例）；讲道理。

**依据**：「见好就收」「给女生一点想象空间」「不要习惯性接收负能量」「转折点出现后一周内邀约」。

### 邀约

**适用信号**：聊得顺、有共同想做的事、她提过想吃什么想去哪。

**目标**：把线上热度变成一次具体见面。

**可用策略**

1. 具体化：时间 + 地点 + 由头，给二选一。
2. 低压力：给一个「拒绝也不尴尬」的由头。
3. 先铺垫再抛：先聊到那家店、那件事，再说「正好」。
4. 被拒：接住 + 留门 + 不追问原因；隔一段时间换个由头再来。

**句式骨架**：由头 + 时间二选一 + 一句轻松兜底

**正例**：「周六下午那家新开的咖啡店据说不错，去试试？你周六还是周日方便。」
**反例**：「改天一起吃个饭吧。」（没有时间地点，等于没邀）

**禁忌**：模糊邀约；「你什么时候有空」；被拒后立刻二次施压；追问「为什么不去」。

**依据**：材料里对「具体邀约 vs 模糊邀约」的原话对比，以及「机会出现一周内邀约」。

### 冲突修复

**适用信号**：她在生气、说「随便」「没事」、已读不回，或你们刚有过争执。

**目标**：先降情绪，再谈事情。顺序反了，说什么都是错的。

**可用策略**

1. 承认具体行为，不笼统道歉：「我昨天答应六点到，结果八点才到」，不是「对不起我错了」。
2. 说自己的感受和打算，不指责对方。
3. 给一个可执行的小补偿或明确边界，不空口保证。
4. 冷处理要有期限：说清楚「我今晚想一下，明天找你」，别无限消失。
5. 对方要空间就给空间，留一句「我在」。

**句式骨架**：我理解你……（情绪）+ 我这边确实是……（具体）+ 我想……（下一步）

**禁忌**：讲道理赢辩论；翻旧账；「你要这么想我也没办法」；冷暴力；连环消息轰炸；当场逼对方给答复。

**依据**：话术整理里「不要跟女生讲道理，顺着她的思路讲」，转化成「先接情绪，再讲事实」；其余为通用沟通原则。

## 三、阶段 × 情绪 怎么配

| | 破冰 | 升温 | 邀约 | 冲突修复 |
| --- | --- | --- | --- | --- |
| **积极** | 抓一个点聊深，别铺太开 | 最佳组合：加码、埋钩子 | 直接抛具体邀约 | 先认错再谈，别急着修复关系 |
| **中性** | 给具体、给选择，别连问 | 给情绪价值，降回复成本 | 先铺垫由头，别硬邀 | 先给空间，别追问 |
| **冷淡** | 换话题再来一次，两次就停 | 减量，别追 | 不邀，等热度回来 | 只给一句台阶，不解释 |
| **试探** | 幽默接住，别自证 | 接住 + 轻微表态 | 用玩笑试探意愿，别正式邀 | 不接招，先降温 |

**禁用组合**：对方冷淡或冲突进行中，不要用暧昧。这两种情况下暧昧只会显得轻浮或施压。

---

## 四、判断不了的时候

- 情绪判不准：按「中性」处理，回复里给具体的东西，通常不会错。
- 阶段判不准：按更早的那个阶段处理（宁可当破冰，不当邀约）。
- 上下文只有一句：在输出开头写明假设，别硬编前情。
