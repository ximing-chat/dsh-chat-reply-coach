## 从「话术整理」里提炼了什么

原文是一份口语课程记录，这里做的是提炼而不是照搬：

- **轻松有趣的基调** → 破冰阶段的目标写进 `stage-strategies.md`
- **反对查户口式聊天、微信短小精悍** → 破冰禁忌 + 长度对照表
- **抓关键词发散、看到什么都能讲故事** → 破冰策略 1
- **见好就收、留白** → 升温禁忌 + 埋钩子
- **不要习惯性接收负能量** → 升温禁忌
- **回复频率变快、篇幅变大 = 转折点，一周内邀约** → 升温策略 5 + 邀约时机
- **具体邀约 vs 模糊邀约** → 邀约的正例反例
- **暧昧到「想你了」为止，见面之前不聊性** → 暧昧的边界信号
- **不要跟女生讲道理，顺着她的思路讲** → 冲突修复的「先接情绪再讲事实」

## 刻意排除的内容

原文里有几类内容没有带进技能，原因是与本技能的 Rules 冲突：

1. **筛选心态 / 「让她知道是你在筛选她」** —— 把关系当地位博弈，属于操控框架。
2. **跪舔、姿态、谁高谁低** —— 改成「不卑不亢、平等交流」，不做高低位计算。
3. **咨询流程里的私密问诊**（年收入、性生活频率与质量、是否同居、是否单亲等）—— 属于隐私套取，且原文目的是为推售课程做铺垫。技能只保留「先了解情况再给建议」的逻辑。
4. **贴吧多账号顶贴、引导私信加微信** —— 运营投放流程，与「帮人回一句话」无关。
5. **「百分百失败」「必定挽回」这类绝对化表达** —— 与「不承诺百分百有效」的规则冲突。

## 如果以后要更新

- 换话术材料：优先替换 `stage-strategies.md` 里的策略和句式，`SKILL.md` 的流程和 Rules 不用动。
- 加风格：在 `style-playbook.md` 里加一节，同时在 `SKILL.md` 的「三种风格」表里加一行。
- 加阶段：改 `stage-strategies.md` 的四节结构，并同步 `SKILL.md` 工作流程第 2 步和输出格式里的枚举。
