## 一、三个接话模板

### 1. 鹦鹉回话：复述关键词 + 接情绪

公式：把对方话里的关键词重复一遍（不是整句），再加一句情绪判断。

- 她：「昨天加班到凌晨，累死了」→ 你：「加班到凌晨？你也太拼了」
- 她：「最近有点烦」→ 你：「烦什么了」
- 她：「我妈又催我」→ 你：「又催？催到哪一步了」

反例：「辛苦辛苦」「哈哈哈」「抱抱」——听着像没听，等于没接。

### 2. 关键钩子：抓一个细节追问

公式：地点 / 时间 / 人物 / 事件 / 经历，挑一个问，别一次问三个。

- 她：「周末去爬山了」→ 你：「哪座山，累不累」
- 她：「刚看完一部剧」→ 你：「哪部，值得追吗」
- 她：「今天见了个客户」→ 你：「难缠的那种？」

反例：「挺好的，放松一下」——把话聊死了。

### 3. 情绪延伸：肯定 + 共情 + 顺势问

公式：先肯定她话里的某个特质，再共情，再顺着往下问一句。

- 她：「我以前练过田径」→ 你：「练田径的很能扛吧，那时候最累的是哪项」
- 她：「我一个人搬的家」→ 你：「一个人搬？我搬一次瘫三天，你怎么扛下来的」

注意：肯定要具体（“很能扛”），别夸成“你好厉害”这种空话。

## 二、把封闭问题改成开放问题

| 别问（只能回是/否） | 改成 |
| --- | --- |
| 你喜欢看电影吗 | 最近哪部电影让你印象深 |
| 周末干嘛 | 周末一般怎么过 |
| 你做什么工作 | 当初怎么入这行的 |
| 你吃辣吗 | 你能吃到什么程度，微辣还是变态辣 |
| 你住哪 | 你那边有什么好吃的 |
| 你平时运动吗 | 你一般怎么动，健身房还是户外 |

---

## 三、把话题聊深：问 → 追 → 说

1. **开放式问**：用“什么、怎么、为什么”开头。
2. **抓关键词追**：她提到“爬山”，就问哪座山、最难的一次。
3. **说一点自己，再把球丢回去**：「我上次爬山差点放弃，你是硬爬型还是慢慢走型」

一轮下来，一个话题能撑十分钟。关键是“听得出来”，不是“想得出来”。

## 四、救场话题（按阶段用）

### 破冰（刚认识，别问太深）

- 你平时下班都干嘛
- 最近有没有什么让你觉得很治愈的小事
- 你手机里听得最多的是哪种歌
- 周末更爱出门还是在家躺着
- 有没有那种做一天都不累的事

### 兴趣（找共鸣）

- 最近在追什么剧/看什么书
- 有没有特别想学但还没学的东西
- 如果突然多放三天假，你最想干嘛
- 旅行你是做攻略派还是随便走

### 生活经历（拉近）

- 你是本地人吗，从小在这长大
- 当初怎么选现在这份工作的
- 朋友一般怎么形容你，你觉得准吗
- 最近有什么小目标

### 价值观（第二次见面之后再用）

- 你理想中的周末是什么样
- 你觉得两个人相处最重要的是什么
- 吵架你是当场说开还是先冷静
- 你更需要陪伴还是各自的空间

## 五、冷场急救四招

1. **就地取材**：聊眼前的东西——「这杯味道挺特别，你常喝这种吗」
2. **用「对了」转场**：「对了，突然想到个事」——比硬切自然
3. **回收旧话题**：把前面聊到一半的捡回来，「你刚说的那个后来呢」
4. **允许沉默**：不是每秒都得有声音，硬填更尴尬

## 六、雷区

- 前任、感情史（尤其第一次聊）
- 收入、存款、房子
- 政治、宗教
- 抱怨工作、抱怨别人（偶尔一次可以，别成习惯）
- 逼问「你觉得我怎么样」
- 查户口：连续三个问题
- 只问不说：像面试
- 过度分析她：把每句话都解读一遍

## 七、按对方这句话选技术

| 对方的表现 | 用哪个 |
| --- | --- |
| 只回几个字、收尾式回答 | 关键钩子，抓一个细节问 |
| 吐槽、抱怨、说累 | 鹦鹉回话 + 一句共情，别急着给方案 |
| 讲经历、讲成就 | 情绪延伸，肯定具体特质再往下问 |
| 说「随便」「都行」 | 别问“你想干嘛”，直接给两个具体选项 |
| 冷场、空气安静 | 四招里挑一个，先就地取材 |
| 反问你、试探你 | 幽默带过，不自证（见 stage-strategies） |

---

## 八、这些技术不是万能的

对方只回单字、隔很久才回、连续两次不接话——说明现在不想聊。这时候用技术只会更烦人，收一句体面的话，停。
