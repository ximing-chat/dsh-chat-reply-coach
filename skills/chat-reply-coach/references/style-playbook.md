# 风格手册：真诚 / 幽默 / 暧昧

工作流程第 4 步卡壳时查这里。三种风格不是三种人设，是同一个人在不同分寸下的说法。

## 共同底线

- 说人话：不用书面语，不堆成语，不用「氤氲」「呢喃」这类网文词。
- 一条一个意思。想说的越多，越要拆开发或干脆不说。
- 「宝」「亲爱的」「乖」这类称呼，除非你们已经这么叫，否则不要主动用。
- 表情符号最多一个，除非对方本来就用。
- 不用网络烂梗开头（「家人们」「谁懂啊」），除非对方先这么说话。

---

## 真诚

**语感**：稳、具体、不表演。像一个靠谱的人在说话，不像在写小作文。

**四种常用句式**

| 用途 | 模板 | 例 |
| --- | --- | --- |
| 接情绪 | 听着就 + 情绪词 + 一句松绑 | 「听着就挺累的，今天先别硬撑了」 |
| 具体夸奖 | 你刚才 + 具体行为 + 效果 | 「你刚才那句回得挺妙的，一般人接不住」 |
| 给信息 | 我也 + 具体经历 + 一句结论 | 「我上周去过那家，排队半小时，但值」 |
| 承认 | 这事我确实 + 具体没做到 | 「这事我确实没考虑到，是我疏忽」 |

**要**：具体名词和动词；说「我」的感受；短句。
**不要**：「你真好」「你是我见过最特别的女孩」；「我保证以后一定」；大段内心独白；「为了你我可以……」。

**三个例句**

1. 「你说你最近睡不好，我这两天也这样，凌晨三点还在刷手机，互相监督早点睡？」
2. 「不用特意找话题，你随便说点今天发生的事，我都挺想听的。」
3. 「刚才那句话我说得急了，我不是那个意思，你听着不舒服我道歉。」

## 幽默

**语感**：像随口一说，不像准备过的。准备好了的幽默最不幽默。

**五个手法**

1. 自嘲：拿自己开刀最安全。「我今天的效率大概等于一只猫。」
2. 夸张：把小事放大到荒谬。「你这一句我能反复看三遍，第四遍开始收费。」
3. 跑题：认真回答一个无关紧要的细节。「你先说清楚，是加珍珠还是不加。」
4. 接梗再拐弯：接住她的说法，拧一下再还回去。
5. 一本正经说胡话：用很严肃的语气说很离谱的事。

**要**：短；有画面；落点轻，说完就过。
**不要**：拿对方外貌、家庭、工作开玩笑；阴阳怪气；一条里塞三个梗；解释自己的梗。

**三个例句**

1. 「行，那我先记下来，2026 年 11 月 7 日，你第一次主动找我。」
2. 「我本来想反驳你，想了想你说得对，那我只能夸你有眼光了。」
3. 「刚我妈问我跟谁聊天笑成这样，我说一个朋友，她说哦——那个『哦』你懂的。」

---

## 暧昧

**语感**：轻、留白、不索取。把普通的事说出一点点特别，然后停住。

**四个手法**

1. 只描述感受，不要求回应：「今天路过你说的那家店，想起你了。」
2. 半句话：「你这一句我得存着。」（不解释存着干嘛）
3. 画面感：「想象了一下你站在那堆书里挑书的样子，有点好笑又有点好看。」
4. 把日常说出一点特别：「跟你说话的时候，时间过得特别快，有点麻烦。」

**要**：点到为止；给对方接话的空间；她接了再往前一点。
**不要**：低俗暗示；查岗（「在干嘛」「跟谁」）；要承诺（「你到底喜不喜欢我」）；索取式提问（「想我了吗」）；见面之前聊性。

**边界信号（出现就退回去）**

- 她只回「哈哈」「嗯」「还行」——说明没接住，退回真诚或幽默。
- 她转移话题——不要再补一句暧昧。
- 她回「你别这样」——立刻收，不要解释成「开玩笑的」再来一次。

**三个例句**

1. 「今天降温，你出门记得多穿点。（不是群发，就跟你说的）」
2. 「刚才想发消息给你，又怕你在忙，纠结了三分钟。」
3. 「你笑起来挺好听的——我是说打字都能看出来。」

---

## 混搭

- **真诚打底 + 一句幽默收尾**：最稳，适合大多数场合。
- **幽默打底 + 一句真诚**：适合对方在试探、气氛有点飘的时候。
- **暧昧只加一句**，多了腻，而且显得急。
- **冲突里不用幽默**，除非对方先开玩笑。

## 长度对照

| 对方发的 | 建议回 |
| --- | --- |
| 1—5 个字 | 5—15 个字，别超过两行 |
| 一句话 | 一到两句 |
| 一段话 | 两到三句，别明显长过对方 |

## 三条自检

1. 这条读出来像这个人平时说话吗？
2. 拿掉表情和语气词，意思还成立吗？（成立才发）
3. 对方看到这条，需要费劲想怎么接吗？（需要就改简单点）

## AI 味黑名单

一眼能看出是 AI 写的，通常栽在这几处。左边出现就删，右边是人的写法。

| AI 写法 | 人话 |
| --- | --- |
| 听起来你今天真的挺累的，要不要先休息一下呢？ | 累了就早点睡，别硬撑 |
| 其实我觉得你可以试着换个角度想这件事 | 换个角度想，也没多大事 |
| 我理解你的感受，这确实让人很为难 | 这事儿换谁都烦 |
| 哈哈，你这么说让我有点受宠若惊 | 你这话说的，我都不好意思了 |
| 不得不说，你的想法很有意思 | 你这想法挺贼的 |
| 或许我们可以找个时间一起吃饭？ | 周六吃饭？ |
| 我只对你一个人这样，真的 | 就对你这样 |
| 某种意义上，这也是一种成长吧 | 反正也不亏 |
| 你觉得呢？ | （直接删掉，别问） |

**六种典型 AI 味**

1. **对称**：三个分句排比、每句字数差不多 —— 真人打字不会这么齐。
2. **完整**：主谓宾齐全、有开头有结尾 —— 真人常常只有半句。
3. **解释**：把潜台词又说一遍（「我不是查岗，只是……」）—— 说破就没劲了。
4. **共情腔**：先复述对方情绪再给建议 —— 这是咨询师，不是男朋友。
5. **金句**：一句俏皮话结构完美 —— 像段子，不像随口说的。
6. **均匀**：三条回复长度、节奏、开头都一样 —— 一看就是批量生成的。

**改法只有一个**：删字、拆句、加一个口语词（就、反正、行吧、也是、得了），然后读一遍。

**人味清单**（有其中两三条就够了，别全塞）

- 一个短句，甚至一个词：「行。」「确实。」
- 一个口语连接：「反正」「就」「那」「也是」
- 一处不完整：「周六？我看看。」
- 一个具体细节（店名、时间、动作），不是形容词
- 标点随意：句末不写句号，用空格或直接断句
