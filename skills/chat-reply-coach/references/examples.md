# 完整示例（单条回复版）

默认只给一条，直接能发。注意例 4 没有梗——冲突里不玩梗。

---

## 例 1：破冰 × 中性

**用户输入**

> 刚加微信两天，之前活动上认识的。我：最近在忙啥？她：哦哦，还行吧，就上班下班。

**输出**

```
【判断】情绪：中性｜阶段：破冰｜依据：「还行吧」+「上班下班」是收尾式回答，没反问，也没关门

【回】上班下班，这四个字我也熟。最近在找好吃的店续命，有推荐吗

为什么：先接住她的「累」，再抛一个她随口能答的具体问题；没查户口，也没硬找话题。
```

---

## 例 2：升温 × 试探

**用户输入**

> 聊了两周，她有时会主动找我。今天我说「忙完了终于能歇会」，她回：「你怎么天天都这么闲啊，是不是对谁都这么有空」

**输出**

```
【判断】情绪：试探｜阶段：升温｜依据：反问 +「对谁都这么」是玩笑式质疑，不是真质问

【回】闲是挺闲的，主要看跟谁

为什么：不辩解「我很忙」，也不自证，把「闲」拐到「你」身上，留一半给她接。
```

---

## 例 3：邀约 × 积极

**用户输入**

> 聊到一家新开的日料，她说「这家我收藏好久了！！就是一直没人陪我去」

**输出**

```
【判断】情绪：积极｜阶段：邀约｜依据：两个感叹号 + 主动说「没人陪我去」，是把门推开的信号

【回】那周六下午去，我排队你负责吃

为什么：时间地点给死，分工一句带过，她只需要点头；比「改天一起去」有用得多。
```

---

## 例 4：冲突修复 × 冷淡（不玩梗）

**用户输入**

> 昨天答应陪她去看展，临时被叫去加班放了鸽子。今天发消息她只回：「随便你吧」

**输出**

```
【判断】情绪：冷淡｜阶段：冲突修复｜依据：「随便你吧」是关门式回答，情绪还在，但不想继续谈

【回】昨天是我不对，答应了又放你鸽子。展到下个月，这周末我空出来，你定

为什么：认具体的事、给具体补偿、不解释加班有多不得已。这时候说俏皮话等于不认错。
```

## 用户明确要多个版本时

只在这种时候给 2—3 条，并指出哪条最稳。

**用户输入**：「她：你还挺会说话的。给我几个版本」

```
【判断】情绪：试探｜阶段：升温｜依据：表面是夸，实际在观察你是不是套路多

【回】完了，被你看出来了，那我收着点
为什么：不辩解，用自嘲把「会说话」变成玩笑，她回「别啊」就往前一步。**这条最稳。**

【备选】
· 会说话这事分人，你让我有话说
· 那以后我少说，多听

【提醒】别选解释型的（比如「我只是实话实说」），越解释越像套路。
```

## 反面示例：同一句话的 AI 版和人版

| AI 版 | 人版 |
| --- | --- |
| 听起来你今天真的很累，建议你早点休息，照顾好自己哦 | 累就早点睡，别硬撑 |
| 我理解你的感受，这确实让人很为难 | 这事换谁都烦 |
| 或许我们可以找个时间一起吃饭？ | 周六吃饭？ |
| 哈哈，你这么说让我受宠若惊 | 你这话说的，我都不好意思了 |
| 不得不说，你的想法很有意思 | 你这想法挺贼的 |
