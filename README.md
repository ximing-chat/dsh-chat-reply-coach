# chat-reply-coach

把一段中文聊天记录变成**一条能直接发出去的回复**——判断情绪、挑对策略、带一个贴着她的话长出来的梗，并说明一句为什么。

> 默认只给一条，不列一堆选项让人挑。

## 它做什么

DSH 技能 `chat-reply-coach` 的插件壳。安装后，技能在整个 profile 的所有工作区可用。

收到聊天内容时，它按固定流程工作：

1. 判断对方最后一条消息的情绪：积极 / 中性 / 冷淡 / 试探
2. 判断当前阶段：破冰 / 升温 / 邀约 / 冲突修复
3. 从内置资料里挑对应策略
4. 写**一条**最合适的回复——像真人微信打字，带一个梗
5. 附一行说明：为什么这句合适

## 安装

```bash
# 在 DSH 会话里，让 Agent 执行：
plugin_manager  install_bundle  target=<本包目录的绝对路径>
```

安装会把它写进当前 profile 的 `dsh.profile.bundles`，并以本地目录链接（`file:`）方式引用。卸载：

```bash
plugin_manager  remove_bundle  target=@local/dsh-chat-reply-coach
```

> 因为装的是目录链接，移动或删除本目录等于卸载。

## 使用示例

**输入**

> 刚认识两周。她：「今天加班到九点，累死了」

**输出**

```
【回】九点…你们公司是按小时收费的吗。早点睡，明天再卷

为什么：先接住「累」，用一句夸张把气氛放轻，最后落回关心；不追问她加班的细节。
```

**再比如**，她说「这家店我收藏好久了，就是一直没人陪我去」：

```
【回】那周六下午去，我排队你负责吃

为什么：时间地点给死，分工一句带过，她只需要点头。
```

冲突场景不会强行玩梗：

```
【回】昨天是我不对，答应了又放你鸽子。展到下个月，这周末我空出来，你定

为什么：认具体的事、给具体补偿、不解释加班。这时候说俏皮话等于不认错。
```

## 数据与隐私

- **无状态**：插件不写入任何文件。它只在启动时读取包内的 `skills/chat-reply-coach/SKILL.md` 和 `meta.json`，把技能注册进当前 profile。
- **不存用户数据**：不读聊天记录、不建缓存、不落盘、不联网。
- **不调用模型**：插件本身没有任何 LLM 客户端；它只提供提示词内容，实际推理由宿主和用户自己配置的凭据完成。
- **日志不含路径**：仅在技能文件读取失败时输出错误码（如 `ENOENT`），不输出文件路径或异常正文。
- 技能内容可以在技能目录中查看，包含参考文档；其中不含任何账号、密钥或用户聊天原文。

## 合规声明

以下规则写在技能正文里，属于不可关闭的硬约束：

- 不生成任何以**欺骗、操控、骚扰**为目的的话术（包括假装身份、多头暧昧、贬低打压、制造焦虑逼表态）
- 不承诺「**一定回复**」「**百分百有效**」——回复只提高沟通质量，不保证结果
- 不生成涉及**金钱索取或隐私套取**的内容（借钱、要转账、要住址、要证件、套问收入、诱导私密照片）
- 对方明确拒绝、拉黑或长期不回时，给体面收尾或建议先停，不提供「再追一条」「换个号试试」
- 涉及未成年、已婚、上下级/师生等权力不对等关系时，先提示风险

## 包结构

```
.
├─ package.json          # dsh.bundle.patch → cordis.patch.yml
├─ cordis.patch.yml      # 插入 id=chat-reply-coach 的插件行
├─ index.js              # 读取 SKILL.md，注册为 runtime skill
├─ icon.svg / locale/    # 插件列表里的图标与中英文标题
└─ skills/chat-reply-coach/
   ├─ SKILL.md           # 技能正文（内容源头）
   ├─ meta.json          # 与 frontmatter 同步的 name/description/whenToUse
   └─ references/*.md    # 阶段策略、接话技术、造梗、示例、来源说明
```

## 维护

- 改内容：直接编辑 `skills/chat-reply-coach/SKILL.md` 或 `references/*.md`
- 改了 frontmatter 的三个键，跑 `node genmeta.mjs` 重新生成 `meta.json`
- 正文在插件激活时读取并注册，改完需重启 Harness 或重新启用插件
